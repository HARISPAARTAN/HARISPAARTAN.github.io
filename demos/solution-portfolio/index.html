The approach

Design decisions — and why

Every tool in this build was chosen deliberately. The guiding principle: solve the business problem with what Nordstern already pays for, and keep a clean upgrade path open.

Data platform

SharePoint Lists, not Dataverse

Both assignments fit comfortably in SharePoint Lists: they are included in Nordstern's Microsoft 365 licences (€0 extra), the data volumes of a project-management firm stay well inside their limits, and every admin already knows them.

  • Lookup columns give real relationships
  • Versioning & recycle bin built in
  • Honest trade-off: at enterprise scale, Dataverse adds row-level security and richer modelling — the design migrates cleanly when that day comes
App model

Power Apps canvas apps

Canvas apps give pixel-level control, so both apps look like products — not like forms. All logic is Power Fx: readable, low-code formulas the team can maintain themselves.

  • Tablet layout for the CRM, phone layout for site QA
  • Full add / edit / delete on every entity
  • Embeds directly as a Teams tab
Automation

Power Automate flows

Reminders and reports are things people forget — so they don't stay with people. Scheduled and on-demand flows run in the tenant, next to the data, on standard connectors.

  • Daily reminder flow — built & tested
  • On-demand PDF report flow — free connectors only
  • No premium licence required for any of it

Assignment 1 — Automation

What runs by itself Built & tested

Flow 1 · scheduled daily

Follow-up reminders

Every morning at 08:00, Power Automate reads the Activities list, picks every open item due today or overdue, and emails the assigned owner. Nothing slips.

Recurrence (daily 08:00) └ Get items: Activities filter: Status eq 'Open' and DueDate le today() └ For each → Send email to the activity's AssignedTo

Tested — reminder emails delivered ✓

Assignment 2 — The report

From site to structured report

1
Capture onceThe inspector records the element, photo, defect status and comment in the app — three taps per element.
2
SharePoint stores itEvery inspection lands in the Inspections list — filterable by project, inspector, date and defect status.
3
Power Automate builds the reportOn demand, a flow collects the project's records, computes the defect summary and assembles the full report — nobody re-types anything.
4
DeliveredSaved to SharePoint / OneDrive and emailed as a PDF, or posted to the project's Teams channel.
Path A · standard licences

HTML → PDF Free connectors

The flow renders a styled HTML report — project details, defect summary with counts, one block per element — then converts it to PDF via OneDrive and emails it. Runs on any Microsoft 365 tenant, no premium licence.

Path B · premium connector

Word template Photos embedded

A delivered Word template with content controls and a repeating section — one block per inspected element, including the captured photo in a picture control. The "Populate a Word template" action fills it and converts to PDF. Same flow, richer output.

Both report formats are in the deliverables: a 12-finding Word report template and an interactive HTML report generated from the same live data.

Capture is entered once and flows straight into the report — no re-typing, no lost photos.
